Made by

One person, one laptop, one event.

Code

Raw HTML, CSS and JavaScript. No frameworks, no build step, no dependencies. Canvas 2D for the rooms, Web Audio for the sound, the DOM for everything you can click.

Assets

Art is AI-generated, then colour-graded and stitched by a Python script. Sound is public-domain (CC0) library material, plus whispers and one line of dialogue recorded by a human with a phone, because a stock voice is never as frightening as a real one.
